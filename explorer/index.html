Explorer

Every family, every mode, in the browser

The renderer the wallpapers are made with, compiled to run here: the same escape-time arithmetic, the same iteration policy, the same modes and palettes. Drag to move, scroll to zoom, then pick a family, a mode and a colour and see what the same place looks like through each of them. The address bar always names the view you are looking at, so a link is the whole picture.
