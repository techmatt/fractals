Every place the search kept

One mark for every location the search has found and a judge has kept, on the parameter plane it came out of. A Julia location is a value of c, and c is a point of that same plane, so both halves of the search are drawn here together. Hover a mark and it gives you three pictures: the Julia set it stands for, its neighborhood on the plane, and the colored render a judge scored. Each of the three opens in the explorer at the view it is.
