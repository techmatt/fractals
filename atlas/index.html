Every place the search kept

One mark for every location the search has found and a judge has kept, drawn on the plane it came out of. The plane behind the marks is rendered here, in the browser, by the same renderer that made the wallpapers; so is every place you settle on that no render judge has looked at yet. Each mark is a link into the explorer at the view it stands for.

Starting the renderer…

If this message stays, the page is being opened straight off the filesystem. A browser will not load a page's modules, its workers or its renderer over file://, so this page needs to be served — python -m builder serve puts this tree on localhost — or read at techmatt.github.io.
